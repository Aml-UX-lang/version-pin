Version Pin

A Figma plugin that keeps every version of a screen or page in the file and makes the final one obvious to developers. This prototype runs the real plugin code. Click frames and pages on the left and use the panel on the right. Switch to Dev Mode to see what a developer sees, and watch the team channel below the canvas for Slack or Teams messages.
